# RRX – Video-Wissensdatenbank

Die [RRX2026-Wissensdatenbank](RRX2026-Wissensdatenbank.md) enthält ein Themenregister, eine Videoübersicht und zeitmarkierte Transkripte. Sie erschließt 73 öffentlich verlinkte Videos der [RRX2026-Videoseite](https://rr-schema.de/rrx2026.html) sowie ein ergänzendes Transkript ohne öffentlichen Videolink.

Die Transkripte wurden automatisch aus den Tonspuren erzeugt. Fachbegriffe, Namen und Zahlen können falsch erkannt sein; rein visuelle Schritte sind darin nicht vollständig beschrieben. Für eine verlässliche Anleitung das jeweilige Video an der verlinkten Zeitmarke ansehen.
